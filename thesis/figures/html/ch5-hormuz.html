The Strait of Hormuz stays closedWhat happens to the world gas market over one year?
Strait closed

1Question

AnalystWaits about a month to see whether the closure lasts, then decides to start a study.

2Scenario

AnalystDescribes the storyline: One year, strait open or closed, and Russian supply also cut.
Scenario agentProposes about 90 nodes instead of 136, with no seasons or storage. Blocks every LNG route out of the Gulf with very large distances, and asks about Gulf market power and pipeline expansion.
AnalystApproves the node structure and the edits.
CodeCreates the variants. They differ only in the general workbook.

3Data

Data agentMaps sources to the new nodes, drafts one year of projections, and proposes an elasticity class for each node.
CodeAggregates pipeline capacities and recomputes shipping distances.
Data agentSuggests the official domestic price as the Gulf reference price.
AnalystReplies: That price is subsidised, far below what the model needs.
Data agentRevises the value and proposes a lesson about subsidised prices.
AnalystApproves the lesson. It is applied to the other countries with subsidised prices.

4Calibration On the baseline, with the strait open

Calibration agentDiagnoses the deviations and proposes one change at a time.
Code and GGMApply the change, run the model and report the new deviations; the two repeat.
AnalystFollows the log, corrects one diagnosis, and accepts the fit.

5Runs and results

Code and GGMRun every variant with the same calibration.
Results agentDrafts where the missing LNG is replaced and which importers lose most, with the tables behind it, and flags odd patterns.
AnalystsDecide what the results show and write the findings.
