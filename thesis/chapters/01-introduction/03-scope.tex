\section{Scope}

This project thesis establishes where agents could be used around GGM and what that would require; it does not build or evaluate them, which is the task of the master's thesis in spring 2027.
Its conclusions are therefore arguments from the model's documentation, code and data and from the literature, not measured results.
It concerns GGM only, as documented for version 3.0 \citep{egging2019global} and as implemented in the current Julia version \citep{ggmpublicongithubndggm}, and takes the model itself as given.
It studies how the workflow is carried out, not whether any particular dataset or result is right; the 2023 dataset provided by the developers serves as illustration.
Where the description of the workflow is inferred from documents rather than confirmed by the developers, this is stated.
