            What each agent card will show

            GetsIts inputs: which workbook sheets, which documents, which earlier results
            ProducesIts output, and in what form a person reviews it
            ToolsThe code it may call: readers, validators, the model run itself
            Never doesFor example arithmetic in its head, or changing calibrated values without sign-off
            Human gateWhere a person approves before anything moves on
            Works ifHow we would know it worked, and against what

            From the job description in docs/project-thesis-structure.md §5.

            How to add one

            Create agents/registry.json with a list of agents, run python3 overview/build.py, and republish. Each entry looks like this:

            {
  "name": "Calibration explainer",
  "step": "calibrate",
  "status": "idea",
  "gets": "Deviation report from a run",
  "produces": "Written diagnosis, ranked",
  "tools": ["read_results", "docs_search"],
  "neverDoes": "Edits calibrated values",
  "humanGate": "Analyst approves any change",
  "worksIf": "Matches doc heuristics, p. 28"
}

            step is one of source, prepare, scenario, calibrate, run, results. The example is illustrative only.
